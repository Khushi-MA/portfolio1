Hey there! Welcome to the source code of my personal portfolio. This is a simple, responsive React application designed to showcase my journey as a Software Developer, Data Enthusiast, and Student Leader.


---

## 🚀 Tech Stack

- **Frontend:** React.js
- **Styling:** CSS3 (with a focus on responsiveness)
- **Icons & UI:** FontAwesome / Flaticons
- **Deployment:** Netlify / GitHub Pages

---
## 🛠️ What's Inside?

This portfolio is built to bridge the gap between my technical projects and my management experience. It covers:

- **SDE Experience:** Details of my work at Haegl Technologies, focusing on Django, SQL, and system performance.
- **Data Science:** Automating data scraping and trend analysis from my time at BCI/NCF.
- **Leadership:** My journey as Student President of *Make in BVB (MiB)*, managing teams of 50+.
- **Research:** Links to my published IEEE and Springer papers on NFTs and Sentiment Analysis.
